# Policy activation acknowledgement gap

이 디렉터리는 실험 **설계만** 보관한다. 실행기와 결과는 없다.

질문은 정책 API 객체의 생성 성공 응답이 실제 집행 준비 완료까지 보장하는지이다. 무해한 ConfigMap을 대상으로, 정책 생성 직후 요청과 정책 상태가 준비된 뒤의 요청을 비교한다. 즉시 요청만 허용되고 준비 후 같은 요청이 정책 고유 메시지와 함께 거부될 때에만 활성화 간격을 관찰한 것으로 판정한다.

현재 우선순위는 낮다. 간격이 존재하더라도 일시적이며 각 제품이 준비 상태를 제공하기 때문이다. 정상 운영 중 지속되는 하위 리소스 미탐과 공개 정책 번들의 표준 드리프트를 먼저 검증한다. 상세 설계와 중단 조건은 [PROTOCOL.ko.md](PROTOCOL.ko.md)에 있다.
